# Room photographs: The Peaks Resort

Photos dropped in this folder appear on /telluride ("Where you stay"), on each
Telluride trip page, and on the package cards and order summary at checkout.
A photo only shows once its file exists here under exactly the name below, so
add them in any order; until a package has one, it shows a typographic panel
instead of a picture.

**Format:** landscape 3:2, 2400px wide (2400 x 1600), JPEG, sRGB, under about
800 KB each. The `-1` photo of each package is its hero and the checkout card
image, so make it the room at its best, shot wide, in daylight.

the picture.
